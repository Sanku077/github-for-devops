------------------Welcome to Git GitHub----------------

1. Basic Git Commands:
    
    1. git init :
        Initalize the repo locally
    2. git status: 
        To show changed files & current status
    3. git add .:
        To add all the files to staging
    4. git add filename:
        To add specific files to staging
    5. git rm --cached filename:
        To remove the specific files from staging
    6. git commit -m "Message":
        To commit the changes
    7. git restore filename:
        To discard the changes in working directory(Suppose if someone delete the files so it will restore it that files must be tracked)
    8. git clone <repo-url>:
        To clone an existing repository
    9. git log :
        show commit history

2. Configuration:

    1. git configure --global user.name "Your Name"
    2. git configure --global user.email "Your Email"

3. Advance commands

    1. git remote add origin <url>:
        To connect the remote repo (add a remote repository named origin that points to that specified url)
    2. git remote -v:
        List all remote connections with their URLs - verifies your remotes are set up correctly
    3. git push origin master:
        It will push all the changes happen in local to github repository
    4. git pull origin master:
        It will pull all the changes happen in github to local
    5. git remote remove origin:
        delete the remove
    6. git remote rename origin newname:
        Rename a remote
    7. git remote set-url origin <url>:
        change the remote url
    8. git remote show origin:
        Show detailed info about remote
    9. git
        New command
    10. git clone url:
        clone the repo from url to local

4. Git Branching commands

    1. git branch:
        show all the branches
    2. git fetch:
        fetch all the branches from github
    3. git branch -v:
        show last commit on each branch
    4. git branch branch_name:
        create new branch
    5. git switch branch_name: or git checkout branch_name
        switch to the given branch
    6. git checkout -B branch_name:
        Its an advance command where we create and switch to the new created branch in single command.
    7. git branch -m old_name new_name:
        To rename the branch
    8. git branch -d branch_name:
        To delete the branch in safe mode (It will allow to delete only merged branch).
    9. git branch -D branch_name:
        To delete the branch (It will allow non/unmerged branch also).
    10. git push origin branch_name:
        Push branch to remote
    11. git pull origin branch_name:
        pull remote branch to local
    12. git branch -vv:
        tracking info + last commit.
    13. git branch --merged:
        It will show branches merged into current branch
    14. git branch --no-merged:
        It will show branche not yet merged.
    15. git rebase -i HEAD-3:
        Give vi like editor to edit last 3 commit.
    16. git rebase -i HEAD-5:
        Give vi like editor to edit last 5 commit.
    17. git rebase -i branch_name:
        Give vi like editor to edit all commits in given branch.
