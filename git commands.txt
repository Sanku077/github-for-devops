------------------Welcome to Git GitHub----------------

1. Basic Git Commands:
    
    1. git init :
        Initalize the repo locally
    2. git status: 
        To show changed files & current status
    3. git add .:
        To add all the files to staging
    4. git add filename:
        To add specific files to staging
    5. git rm --cached filename:
        To remove the specific files from staging
    6. git commit -m "Message":
        To commit the changes
    7. git restore filename:
        To discard the changes in working directory(Suppose if someone delete the files so it will restore it that files must be tracked)
    8. git clone <repo-url>:
        To clone an existing repository
    9. git log :
        show commit history

2. Configuration:

    1. git configure --global user.name "Your Name"
    2. git configure --global user.email "Your Email"

3. Advance commands

    1. git remote add origin <url>:
        To connect the remote repo (add a remote repository named origin that points to that specified url)
    2. git remote -v:
        List all remote connections with their URLs - verifies your remotes are set up correctly
    3. git push origin master:
        It will push all the changes happen in local to github repository
    4. git pull origin master:
        It will pull all the changes happen in github to local
    5. git remote remove origin:
        delete the remove
    6. git remote rename origin newname:
        Rename a remote
    7. git remote set-url origin <url>:
        change the remote url
    8. git remote show origin:
        Show detailed info about remote
